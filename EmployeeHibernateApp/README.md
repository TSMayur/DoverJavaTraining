# Employee Hibernate + HQL Assignment

## Setup

1. Run `database/employee_setup.sql` in MySQL Workbench.
2. Copy `src/main/resources/db.properties.example` to `db.properties` and set local MySQL credentials.
3. In Eclipse: right-click **EmployeeHibernateApp** → **Maven** → **Update Project**.
4. Run `com.training.employee.EmployeeHqlApp`.

Enter a number from `1` to `20` to run the matching HQL assignment question.

Questions 19 and 20 change database data. Re-run `employee_setup.sql` to reset all 20 employee records.
